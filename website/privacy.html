PRIVACY

Your clips stay yours.

ShoreClips is a local-first preview application. This statement describes the current prototype, not future cloud features.

Local recordings

Clips are stored in the ShoreClips folder under your user Videos directory. They are not uploaded by the current prototype.

Screen and microphone permissions

Screen recording and optional microphone capture use operating-system permissions. Capture occurs only after you select a source and start the replay buffer, or enable automatic buffer startup.

Future services

Login, cloud sharing, and analytics are not implemented in this preview. If these features are added, this policy must be updated before launch.

Contact

For support, use the repository at github.com/shorebuild/ShoreClips.
